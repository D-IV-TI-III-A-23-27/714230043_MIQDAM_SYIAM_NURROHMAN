Apa itu Algoritma KNN?

Memahami konsep dasar K-Nearest Neighbors dalam Machine Learning

K-Nearest Neighbors (KNN)

K-Nearest Neighbors (KNN) adalah algoritma supervised learning yang digunakan untuk klasifikasi dan regresi. Algoritma ini bekerja berdasarkan prinsip sederhana: "sebuah data baru diklasifikasikan berdasarkan mayoritas kelas dari K tetangga terdekatnya."

KNN termasuk dalam kategori lazy learner atau instance-based learning, artinya algoritma ini tidak membangun model secara eksplisit saat fase training. Sebagai gantinya, seluruh data training disimpan dan digunakan langsung saat melakukan prediksi terhadap data baru.

Supervised Learning

Memerlukan data training yang sudah memiliki label kelas untuk melakukan klasifikasi

Lazy Learner

Tidak membangun model saat training semua komputasi dilakukan saat prediksi

Non-Parametrik

Tidak mengasumsikan distribusi data tertentu, fleksibel untuk berbagai jenis data

Klasifikasi & Regresi

Dapat digunakan untuk kedua tugas: prediksi kelas (klasifikasi) dan nilai kontinu (regresi)

Bagaimana KNN Bekerja?

Ketika data baru masuk, KNN menghitung jarak antara data tersebut dengan seluruh data training. Kemudian, algoritma memilih K data terdekat (nearest neighbors) dan melakukan majority voting kelas yang paling banyak muncul di antara K tetangga tersebut akan menjadi prediksi untuk data baru.

Proses Langkah demi Langkah

Animasi detail setiap tahapan algoritma KNN

1

Simpan Data Training

KNN tidak membangun model saat training (lazy learner). Semua data training disimpan di memori untuk digunakan saat prediksi.

2

Terima Data Baru

Saat data baru masuk, algoritma mulai menghitung jarak ke semua data training yang tersimpan.

3

Hitung Jarak (Euclidean Distance)

Rumus: d = √((x₂−x₁)² + (y₂−y₁)²)

Jarak dihitung antara data baru dan setiap data training.

Euclidean Distance
d(p, q) = √( Σ (pᵢ − qᵢ)² )
4

Urutkan & Pilih K Terdekat

Semua jarak diurutkan ascending, lalu pilih K data terdekat.

5

Majority Voting

Hitung jumlah masing-masing kelas di antara K tetangga. Kelas terbanyak = prediksi akhir.

05

Metode Perhitungan Jarak

Perbandingan visual metode pengukuran jarak yang digunakan KNN

Euclidean Distance

Paling Umum
d = √( (x₂−x₁)² + (y₂−y₁)² )

Jarak garis lurus antara dua titik. Cocok untuk data kontinu dengan skala seragam.

Manhattan Distance

City Block
d = |x₂−x₁| + |y₂−y₁|

Jarak mengikuti sumbu grid (seperti jalan di kota). Cocok untuk data dengan fitur independen.

06

Kelebihan & Kekurangan

Memahami kapan KNN cocok digunakan

Kelebihan

  • Sederhana dan mudah dipahami
  • Tidak memerlukan fase training
  • Efektif untuk data multi-kelas
  • Dapat digunakan untuk klasifikasi & regresi
  • Non-parametrik (tidak ada asumsi distribusi)

Kekurangan

  • Lambat untuk dataset besar
  • Sensitif terhadap fitur yang tidak relevan
  • Memerlukan normalisasi data
  • Curse of dimensionality
  • Pemilihan K yang tepat sangat penting
